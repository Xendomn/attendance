## 系统概述

直播平台观影者智能监控管理系统是一套专业的直播观众行为监控和管理解决方案，旨在为直播平台提供全面的观众监控、行为分析、异常检测和智能管理功能。

### 系统特点

- **实时监控**: 对直播观众进行7×24小时实时监控
- **智能分析**: 基于AI算法的观众行为分析和异常检测
- **可视化展示**: 2.5D园区可视化和BIM集成展示
- **报警管理**: 智能报警和派单处理系统
- **数据统计**: 全面的数据统计和报表生成

### 系统架构

系统采用分布式微服务架构，主要包括：

- **前端展示层**: 基于Vue.js 3.0的响应式Web界面
- **业务逻辑层**: 基于.NET 6.0的微服务架构
- **数据存储层**: SQL Server 2019 R2数据库
- **缓存层**: Redis分布式缓存
- **消息队列**: SignalR实时通信

![系统架构图](images/system_architecture.png)

## 系统登录

### 登录页面访问

1. 打开浏览器，输入系统访问地址：`https://your-domain.com/login`
2. 系统支持以下浏览器：
   - Chrome 90+
   - Firefox 88+
   - Safari 14+
   - Edge 90+

![登录页面](images/login_page.png)

### 登录步骤

#### 步骤1：输入登录信息

1. 在"用户名"字段输入您的用户名
2. 在"密码"字段输入您的密码
3. 如果启用了验证码，请输入图形验证码

![登录表单](images/login_form.png)

#### 步骤2：选择登录选项

- **记住密码**: 勾选此选项可在下次访问时自动填充密码
- **自动登录**: 勾选此选项可在下次访问时自动登录（建议仅在个人设备上使用）

#### 步骤3：完成登录

点击"登录"按钮完成登录过程。系统将验证您的凭据并跳转到系统首页。

### 登录故障排除

#### 常见登录问题

1. **用户名或密码错误**
   - 检查用户名和密码是否正确
   - 注意大小写敏感
   - 联系管理员重置密码

2. **验证码错误**
   - 点击验证码图片刷新
   - 确保输入的验证码与图片一致

3. **账户被锁定**
   - 连续登录失败5次后账户将被锁定30分钟
   - 联系系统管理员解锁账户

4. **网络连接问题**
   - 检查网络连接是否正常
   - 尝试刷新页面或清除浏览器缓存

## 观众状态管理

观众状态管理模块用于监控和管理所有观众的状态和行为。

### 观众列表管理

#### 进入观众管理页面

1. 点击左侧菜单的"观众管理"
2. 选择"观众列表"子菜单

![观众列表页面](images/audience_list.png)

#### 观众信息显示

观众列表显示以下信息：

- **用户ID**: 观众唯一标识
- **用户名**: 观众昵称
- **头像**: 观众头像图片
- **在线状态**: 在线/离线/不活跃
- **当前直播间**: 正在观看的直播间
- **观看时长**: 当前会话观看时长
- **风险等级**: 基于行为分析的风险评分
- **最后活动时间**: 最近一次活动时间

#### 观众状态标识

系统使用不同颜色和图标标识观众状态：

- 🟢 **在线**: 正在观看直播
- 🟡 **不活跃**: 在线但无互动行为
- 🔴 **离线**: 已离开直播间
- ⚠️ **警告**: 存在异常行为
- 🚫 **封禁**: 已被封禁的用户

![观众状态标识](images/audience_status.png)

### 观众详情查看

点击观众用户名可查看详细信息：

#### 基本信息标签页

- 用户基本资料
- 注册时间和来源
- 设备信息
- 地理位置信息
- 网络环境信息

![观众基本信息](images/audience_basic.png)

#### 观看历史标签页

- 历史观看记录
- 观看时长统计
- 偏好直播间分析
- 观看时间分布

![观看历史](images/viewing_history.png)

#### 行为分析标签页

- 互动行为统计
- 弹幕发送记录
- 礼物赠送记录
- 异常行为检测结果

![行为分析](images/behavior_analysis.png)

### 观众操作管理

#### 单个观众操作

对单个观众可执行以下操作：

1. **发送警告**: 向观众发送警告消息
2. **临时禁言**: 禁止观众发送弹幕（可设置时长）
3. **踢出直播间**: 将观众踢出当前直播间
4. **封禁账户**: 封禁观众账户（可设置时长）
5. **解除封禁**: 解除已封禁的观众

![单个观众操作](images/single_audience_actions.png)

#### 批量观众操作

支持对多个观众执行批量操作：

1. **选择观众**: 通过复选框选择要操作的观众
2. **选择操作类型**: 从下拉菜单选择操作类型
3. **设置参数**: 根据操作类型设置相关参数
4. **确认执行**: 确认后执行批量操作

![批量观众操作](images/batch_audience_actions.png)

### 异常观众监控

#### 异常行为检测

系统自动检测以下异常行为：

1. **频繁操作**: 短时间内大量点击、弹幕等操作
2. **恶意内容**: 发送违规、广告等内容
3. **机器人行为**: 疑似自动化程序操作
4. **多账户关联**: 同一用户使用多个账户
5. **网络异常**: 使用代理、VPN等异常网络

#### 风险评分机制

系统为每个观众计算风险评分（0-100分）：

- **0-30分**: 低风险（绿色）
- **31-60分**: 中风险（黄色）
- **61-80分**: 高风险（橙色）
- **81-100分**: 极高风险（红色）

![风险评分](images/risk_scoring.png)

#### 异常观众处理流程

1. **自动检测**: 系统自动检测异常行为
2. **风险评估**: 计算风险评分和等级
3. **报警生成**: 高风险观众自动生成报警
4. **人工审核**: 管理员审核异常情况
5. **处理措施**: 根据情况采取相应措施

## 历史回放功能

历史回放功能允许用户查看和分析历史监控数据。

### 进入历史回放

1. 点击左侧菜单的"数据分析"
2. 选择"历史回放"子菜单

![历史回放页面](images/history_playback.png)

### 时间范围选择

#### 快速时间选择

提供常用时间范围的快速选择：

- 最近1小时
- 最近6小时  
- 最近24小时
- 最近7天
- 最近30天

#### 自定义时间范围

1. 点击"自定义时间"
2. 选择开始日期和时间
3. 选择结束日期和时间
4. 点击"确认"应用时间范围

![时间范围选择](images/time_range_selection.png)

### 回放数据类型

可以回放以下类型的历史数据：

1. **观众数量变化**: 各直播间观众数量的历史变化
2. **互动行为统计**: 弹幕、点赞、礼物等互动数据
3. **设备状态历史**: 监控设备的历史状态变化
4. **报警事件记录**: 历史报警事件的发生和处理过程
5. **系统性能指标**: 系统CPU、内存、网络等性能数据

### 回放控制面板

历史回放提供类似视频播放器的控制界面：

#### 播放控制

- **播放/暂停**: 控制回放的播放和暂停
- **播放速度**: 支持0.5x、1x、2x、4x、8x播放速度
- **进度条**: 显示回放进度，支持拖拽跳转
- **时间显示**: 显示当前回放时间点

![回放控制面板](images/playback_controls.png)

#### 数据筛选

- **直播间筛选**: 选择要回放的特定直播间
- **数据类型筛选**: 选择要显示的数据类型
- **阈值设置**: 设置数据显示的阈值条件

### 回放数据展示

#### 时间轴视图

以时间轴形式展示历史事件：

- 事件时间点标记
- 事件类型图标
- 事件详情预览
- 支持点击查看详情

![时间轴视图](images/timeline_view.png)

#### 图表视图

以图表形式展示数据变化趋势：

- 折线图：显示数值变化趋势
- 柱状图：显示分类数据对比
- 饼图：显示比例分布
- 热力图：显示时间和数值的关系

![图表视图](images/chart_view.png)

### 回放数据导出

支持将回放数据导出为多种格式：

1. **Excel格式**: 适合进一步数据分析
2. **CSV格式**: 通用的数据交换格式
3. **PDF报告**: 包含图表的完整报告
4. **图片格式**: 导出图表为PNG/JPG格式

![数据导出](images/data_export.png)
