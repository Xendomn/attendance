# 直播平台观影者智能监控管理系统

## 项目概述

本项目是一个完整的直播平台观影者智能监控管理系统，旨在为直播平台提供全面的观众监控、行为分析、异常检测和智能管理功能。

## 系统特点

- 🔍 **实时监控**: 7×24小时实时监控直播观众行为
- 🤖 **智能分析**: 基于AI算法的观众行为分析和异常检测
- 📊 **可视化展示**: 2.5D园区可视化和BIM集成展示
- 🚨 **报警管理**: 智能报警和派单处理系统
- 📈 **数据统计**: 全面的数据统计和报表生成

## 技术架构

### 后端技术栈
- **开发语言**: C# 10.0
- **开发框架**: .NET 6.0
- **数据库**: SQL Server 2019 R2
- **缓存**: Redis 6.2+
- **实时通信**: SignalR Core 6.0
- **开发工具**: Visual Studio 2019

### 前端技术栈
- **框架**: Vue.js 3.0
- **UI组件**: Element Plus 2.0+
- **图表库**: ECharts 5.0+
- **视频播放**: Video.js 8.0+

### 部署环境
- **应用服务器**: Microsoft IIS 10.0
- **操作系统**: Windows Server 2019/2022
- **容器化**: Docker 20.10+ (可选)
